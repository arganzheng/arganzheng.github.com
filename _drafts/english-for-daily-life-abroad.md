第 01 篇录音里「描述你的周末」只撑了 45 秒。工作场景我有十几年的背景知识兜底——即使词不够，我知道对方会问什么、流程是什么。生活场景没有这个底：我不知道海外的 GP 看病是什么流程、租房合同里有什么条款、银行开户要问什么，所以不只是词不会，是**不知道要说什么**。

这一篇是生活场景的预习。它和第 06 篇一样不占季度，是第 03 篇词汇场景表和第 04 篇口语话题的语料。写在出国前，所以里面的流程是从资料和朋友的经验里整理的，会有错；出国后按真实经历重写。

## 二、租房

流程（以英美澳的常见情况为准，细节各地不同）：找房源（Zillow / Rightmove / Domain 等）→ 预约看房（viewing / inspection）→ 申请（要收入证明、推荐人、信用记录——新来的人通常没有信用记录，这是第一个要说清的事）→ 签租约（lease / tenancy agreement）→ 付押金（deposit / bond）和第一个月房租 → 入住检查（move-in inspection，拍照）→ 水电网（utilities）自己开通。

| 我要说的 | 句式 |
|---|---|
| 预约看房 | `Hi, I'm calling about the two-bedroom on X Street — is it still available? Could I arrange a viewing this week?` |
| 看房时问 | `What's included in the rent — utilities, internet?` / `How long is the lease?` / `Is there a minimum term?` / `What's the notice period?` / `Is the deposit refundable, and under what conditions?` / `Is it furnished?` / `How's the phone signal / heating / water pressure?` |
| 没有信用记录 | `I've just relocated from China for work, so I don't have a local credit history yet. I can provide my employment contract and pay slips, and I'm happy to pay a larger deposit or a few months upfront if that helps.` |
| 谈条件 | `Would you consider X?` / `Is there any flexibility on the rent / move-in date?` |
| 报修 | `The heating isn't working — could you send someone to take a look?` / `There's a leak under the kitchen sink.` |
| 退租 | `I'd like to give notice — my last day will be X.` / `When can we do the move-out inspection?` |

| 对方会问 | 意思 |
|---|---|
| `When are you looking to move in?` | 什么时候入住 |
| `Can you provide references?` | 推荐人（前房东、雇主） |
| `What's your annual income?` / `Do you have proof of income?` | 收入证明 |
| `Will anyone else be living with you?` / `Any pets?` | 同住人、宠物 |
| `The bond is four weeks' rent.` | 押金四周房租 |

词汇：第 03 篇场景表第 1 周。特别注意 `lease` 既是名词也是动词、`notice` 是「通知期」、`bond` 在澳洲 = `deposit`。


## 三、银行

流程：预约或直接去分行 → 带护照、签证、地址证明（address proof——刚到没有地址证明是第二个要说清的事，通常租约或雇主信可以）→ 开支票 / 储蓄账户 → 拿卡 → 设网银 → 告诉雇主账号收工资。

| 我要说的 | 句式 |
|---|---|
| 开户 | `I'd like to open a checking account (美) / current account (英) / everyday account (澳).` |
| 地址证明 | `I've just arrived and don't have a utility bill yet — would my lease agreement / employer letter work as proof of address?` |
| 问费用 | `Is there a monthly fee?` / `What are the fees for international transfers?` / `Is there a minimum balance?` |
| 转账 | `I'd like to make a wire transfer / international transfer.` / `What's the SWIFT code?` |
| 卡出问题 | `My card was declined — can you check what's going on?` / `I'd like to report my card lost.` |

| 对方会问 | 意思 |
|---|---|
| `Do you have a Social Security Number / National Insurance number / Tax File Number?` | 税号（各国不同，第五章） |
| `Would you like to set up online banking?` | 开网银 |
| `Do you want overdraft protection?` | 透支保护（通常说不要） |
| `Your routing number / sort code / BSB is…` | 银行代码，收工资要给雇主的 |

词汇：场景表第 3 周。三个国家三套词，`checking / current / everyday`、`routing number / sort code / BSB`。定了国家再统一。


## 四、看病与药店

这是生活场景里最需要预习的——生病时没有精力现场组织语言。流程（英联邦国家）：先注册 GP（家庭医生）→ 有事先约 GP，GP 转诊专科 → 急但不危险去 urgent care / walk-in clinic → 危险去 ER / A&E → 药：处方药（prescription）去药店拿，非处方（over the counter, OTC）直接买。美国多一层保险：co-pay、deductible、in-network。

| 我要说的 | 句式 |
|---|---|
| 约 | `I'd like to make an appointment with a GP. It's not urgent.` / `I'd like to register as a new patient.` |
| 描述症状 | `I've had a sore throat and a fever since Tuesday.` / `It hurts when I…` / `The pain is here, it's sharp / dull / throbbing.` / `It comes and goes.` / `I feel dizzy / nauseous / short of breath.` / `I've been having trouble sleeping.` |
| 病史 | `I'm not on any medication.` / `I'm allergic to penicillin.` / `I had X two years ago.` |
| 听不懂医嘱 | `Sorry, could you explain that in simpler terms?` / `How often should I take this?` / `Should I take it with food?` / `Are there side effects I should watch for?` / `When should I come back if it doesn't improve?` |
| 药店 | `I'm here to pick up a prescription for [name].` / `Do you have anything over the counter for a cold / hay fever / a headache?` |

| 对方会问 | 意思 |
|---|---|
| `What brings you in today?` | 怎么了（不是问你怎么来的） |
| `How long have you had it?` / `On a scale of 1 to 10, how bad is the pain?` | 多久了、疼几分 |
| `Any allergies?` / `Are you on any medication?` | 过敏、正在吃的药 |
| `Take one tablet twice a day for seven days.` | 医嘱 |
| `Do you have insurance? Who's your provider?`（美） | 保险 |

词汇：场景表第 2 周。症状词是重点——`sore`（酸痛）、`swollen`（肿）、`itchy`（痒）、`rash`（疹子）、`runny nose`（流鼻涕）、`stuffy nose`（鼻塞）、`cough`（干咳 dry / 有痰 chesty）、`upset stomach`、`diarrhea`、`constipated`。先把自己常见的毛病的英文写下来存在手机里，生病时直接看。


## 五、政府办事

出国第一个月要办的：税号（美 SSN、英 NI number、加 SIN、澳 TFN）、居住登记（部分国家）、驾照换领或考试、医保注册（英 NHS、澳 Medicare、加各省健康卡）。这些流程差异极大，具体的查目的国政府网站，这里只列共用的句式。

| 我要说的 | 句式 |
|---|---|
| 问流程 | `I've just moved here on a work visa. What do I need to do to apply for X?` / `What documents do I need to bring?` / `Do I need an appointment or can I walk in?` |
| 递材料 | `Here's my passport, visa, and proof of address.` / `Is this form filled out correctly?` |
| 没听懂要求 | `Sorry, which form is that?` / `Could you write that down for me?` |
| 问进度 | `I applied three weeks ago — could you check the status?` / `When should I expect to hear back?` |
| 被拒 | `What's missing?` / `Can I resubmit?` / `Is there someone I can speak to about this?` |

规则：政府窗口的人语速不会为你放慢、话常常是半句（`Passport.` `Sign here.` `Next.`），而且用大量本地缩写。**去之前把要办的事和要问的问题写在纸上**，听不懂就把纸给对方看。`Could you write that down?` 是最有用的一句。


## 六、超市、餐厅与日常

这些场景对话短、可预测，主要是词汇（场景表第 4、7 周）。几句高频的：

| 场景 | 句式 |
|---|---|
| 超市 | `Excuse me, where can I find the X?` / `Do you have this in a smaller size?` / `Paper or plastic?`（对方问）/ `Do you need a bag?` / `Would you like a receipt?` |
| 收银 | `Cash or card?` / `Tap or insert?` / `Do you have a loyalty card?` / `That'll be $23.50.` |
| 餐厅 | `A table for two, please.` / `Could I see the menu?` / `What do you recommend?` / `I'll have the X.` / `Could we get the bill / check, please?` / `Can we split it?` / `Is service included?` |
| 点咖啡 | `A medium latte, please.` / `For here or to go?` / `Any milk preference?` / `Name for the order?` |
| 外卖和快递 | `I'm calling about my order — it hasn't arrived.` / `Can you leave it at the front desk?` |
| 理发 | `Just a trim, please.` / `Shorter on the sides, leave the top.` / `About this much off.` |
| 问路 | `Excuse me, how do I get to X?` / `Is it walking distance?` / `Which platform for the train to X?` |

小费和分账的规则各国不同（美国 18–20%、英澳一般不强制），这是文化不是语言，到了再学。


## 七、Small talk 与社交

Small talk 是中国工程师最不适应的场景，因为它在中文职场里几乎不存在。规则：

- **它是必需的**。电梯里、会议开始前两分钟、茶水间——沉默在英文文化里比在中文里更尴尬。
- **它不传递信息**，传递「我对你友善」。所以内容不重要，有回应就行。
- **有安全话题和禁区**。安全：天气、周末、假期、通勤、体育、食物、对方桌上的东西、共同经历的事（`how was the offsite?`）。禁区：收入、年龄、婚育、宗教、政治、体重外貌、`why don't you have kids`。中文里常见的「你多大」「结婚了吗」「房子多少钱买的」全是禁区。
- **有固定的开场和收尾**。

| 功能 | 句式 |
|---|---|
| 开场 | `How's it going?` / `How was your weekend?` / `Busy day?` / `Any plans for the weekend?` / `Cold out there today, huh?` |
| 回应 | `Not bad, yourself?` / `Pretty good — we went hiking on Saturday, it was great.` / `Same old, same old.` |
| 展开 | `Oh nice, where did you go?` / `How was it?` / `I've been meaning to try that.` |
| 我的话题 | `I just moved here from China a couple of months ago — still figuring out where to get decent coffee.` |
| 收尾 | `Anyway, I should get back to it.` / `Good catching up!` / `See you at standup.` / `Have a good one.` |
| 被问到中国 | 准备两三个自然的回答：`It's a big change — mostly the pace, and I miss the food.` |

对 `How are you?` 的回答是 `Good, you?`，不是真的回答。对 `We should grab lunch sometime` 的回答是 `Yeah, definitely`，不一定真的要约——除非对方说了具体时间。这两条是最常见的误会。

练法：第 04 篇话题第 10 周；每周的真人口语前 5 分钟就是 small talk，不要跳过它。


## 八、电话：最难的形态

电话是所有场景里最难的：没有表情和手势、有噪音和压缩失真、对方语速不放慢、还常常是自动语音菜单。而且很多事只能打电话——预约医生、问银行、和房东、投诉快递。

规则：

1. **打之前写好**：我要什么（一句话）、可能被问到的信息（账号、地址、日期、拼写）、想问的问题。写在纸上，对着念不丢人。
2. **开头报家门**：`Hi, my name is X, I'm calling about Y.` 让对方知道这个电话的目的。
3. **拼写**：名字和地址一定会被要求拼写，用 NATO 字母表或者常见词（`A for apple`）；提前把自己名字的拼法练熟——`Z-H-E-N-G, Z as in Zebra`。
4. **听不懂就说**：`Sorry, the line's a bit bad — could you repeat that?` / `Could you speak a little slower? I'm not a native speaker.` 后一句完全可以说，效果很好。
5. **确认**：挂之前复述一遍 `So that's Tuesday the 14th at 3 pm, at the X Street clinic — is that right?`
6. **自动菜单**：`Press 1 for…` 听不清就等，它会重复；或者按 0 / 说 `representative` / `agent` 通常能转人工。

| 功能 | 句式 |
|---|---|
| 开场 | `Hi, I'm calling to make an appointment / to ask about my account / about a delivery.` |
| 转接 | `Could you put me through to X?` / `Is there someone who handles X?` |
| 等待 | `Sure, I can hold.` |
| 留言 | `Could you ask them to call me back? My number is…` |
| 结束 | `Great, thanks for your help.` / `That's all I needed. Have a good day.` |

练法：第 04 篇的 AI 语音对话本身就接近电话形态（无表情、只有声音）；每两周让 AI 扮演一个「有口音、语速快、不太耐心的接线员」，做一次预约练习。出国后前几个真实电话可以先打给不重要的对象（问一个店的营业时间）练手。


## 九、文化差异：直接与间接

语言之外有一层是**什么话该说、怎么说**。几条和中文习惯差异最大的：

| 中文习惯 | 英文（尤其英美澳职场）习惯 | 影响 |
|---|---|---|
| 请求前铺垫、说明苦衷 | 直接说请求 + 一个理由 | 铺垫太长会让对方不知道你要什么 |
| 拒绝用「我考虑一下」「有点困难」 | `No, I can't do that, but…` 直接说 | 你的「有点困难」会被理解为「可以」 |
| 被夸时否认（「哪里哪里」） | `Thanks!` 接受 | 否认会显得奇怪或者不真诚 |
| 不懂也不问，怕显得笨 | 当场问 | 不问会被认为已经懂了 |
| 道歉频繁（`sorry` 当开头） | 道歉只用于真的做错 | 过多的 sorry 会削弱你的话 |
| 谢谢要说很多次 | 一次就够 | — |
| 对上级用敬语和头衔 | 直呼名字，包括 CEO | 叫 `Mr. Smith` 会显得距离感 |
| 意见留到会后私下说 | 会上说 | 会后说等于没说 |
| 沉默表示思考或尊重 | 沉默表示同意或没兴趣 | 会议里沉默是负面信号 |

英国比美国间接一些（`that's interesting` 可能是「我不同意」，`not bad` 可能是「很好」），澳洲更随意。这些只有到了才能真正学会，出国前知道它们存在就够。

## 十一、本文小结

- 生活场景难在没有背景知识兜底：不只是词不会，是不知道流程和对方会问什么。每个场景先学流程，再学句式。
- 租房和银行第一周就要用，都有「新来的人没有信用记录 / 地址证明」这个坎，句式提前准备。
- 看病提前把自己常见毛病的症状词存在手机里；政府办事带纸、`could you write that down`。
- Small talk 是必需的、不传递信息、有安全话题和禁区、有固定开场收尾；`How are you` 不是问题。
- 电话最难：打之前写好、开头报目的、名字拼法练熟、听不懂就说、挂前复述。
- 文化差异：直接说请求和拒绝、接受夸奖、当场问、少道歉、会上说、沉默是负面信号。
- 本篇写于出国前，出国后按真实经历重写。
