第 01 篇的 Oxford 5000 抽样：100 个 B2–C1 的词，我会用 48 个、认识 27 个、不认识 25 个。不认识的那 25 个几乎全是生活词——`colander`、`landlord`（认识）但 `lease` 的动词用法（不会）、`prescription`（认识）但 `over the counter`（不会）、`sore throat`（会）但 `runny nose`（不会）。

我的词汇是偏科的：技术领域的词汇量可能超过普通母语者，生活领域大概是个十岁小孩。这一篇讲怎么补这个偏科，而且只用每天午饭那 10 分钟加晚上 5 分钟。

## 二、缺口在哪

六级词汇表约 5,500 词，偏向学术和考试阅读：`phenomenon`、`hypothesis`、`legislation`。Oxford 3000 / 5000 是牛津按**使用频率和学习者需要**选的核心词表，标了 CEFR 等级，覆盖日常和通用场景。两者重叠很大，但缺口的形态很有规律：

| 缺口类型 | 例子 | 为什么六级没覆盖 |
|---|---|---|
| **家居和身体** | `faucet / tap`、`drawer`、`mop`、`sore`、`swollen`、`itchy`、`bruise` | 考试阅读不写这些 |
| **办事和制度** | `lease`、`deposit`、`utility bill`、`co-pay`、`deductible`、`direct debit`、`notary` | 中国和目的国制度不同，中文里也不常想到 |
| **动词短语** | `pick up`（取东西 / 接人 / 学会）、`sort out`、`run out of`、`drop by`、`figure out` | 六级词表按单词收，短语动词是口语的主体 |
| **认识但不会用** | `appreciate`、`concern`、`issue`（动词）、`due`、`available` | 读的时候懂，说的时候想不到；搭配（collocation）不会 |
| **语气词和填充词** | `I mean`、`sort of`、`to be fair`、`that said`、`fair enough` | 完全不在任何词表里，但每句话都有 |

最后两类比第一类更重要。生活名词缺了可以指着说 `this thing`，但「认识不会用」的词和语气词直接决定说话的流畅度——第 04 篇口语卡壳的「找不到词」，一半是这两类。


## 三、句子卡，不是单词卡

这是本篇唯一的核心方法。我背过很多轮单词表，`abandon` 开头的那种，全部失败——不是记不住，是记住了也不会用，而且三个月不用就忘。

原因：一个词的意思不在词典释义里，在它的用法里——它和哪些词搭配、出现在什么句式、什么语气。`appreciate` 的词典释义是「感激；欣赏」，但你需要知道的是 `I'd appreciate it if you could…` 这个句式，以及它比 `thank you` 更正式、常用于请求。这些只有句子能带。

### 1. 卡的正面

一个**完整的句子**，目标词或短语挖空或加粗。句子必须是我自己遇到的——听到的、读到的、或者想说而说不出的——不是词典例句。自己遇到的句子带着情境，情境是记忆的钩子。

### 2. 卡的背面

- 目标词 / 短语；
- 一句极简的英文解释或中文意思（一行，不抄词典）；
- 我遇到它的地方（「Changelog 第 612 集」「租房合同模板」）——可选，但很有用；
- 如果是「认识不会用」的词：再加一个**我自己写的句子**，用它说一件我的事。

### 3. 例子

```
正面：
  Can you ______ the kids from school at 3?
  （接、取）

背面：
  pick up
  to collect someone or something from a place
  也用于：pick up a language / pick up the phone / pick up where we left off
  我的句子：I need to pick up my package from the front desk.
```

```
正面：
  I'd ______ it if you could send the report by Friday.

背面：
  appreciate
  礼貌的请求，比 please 更正式；「感激」义
  用于邮件的请求句；口语里 That'd be great 更常见
  来源：同事的邮件
```

一张卡只放一个词或短语。一个词多个意思就多张卡，每张一个句子。


## 四、词从哪来

不背词表，词从输入里**捞**。三个来源，一个流程：

### 1. 三个来源

| 来源 | 什么时候 | 捞什么 |
|---|---|---|
| **听力材料**（第 02 篇） | 晚上听写对文本时 | 「听到了但不认识」那一类错误；反复出现的语气词和短语动词 |
| **口语卡壳**（第 04 篇） | AI 对话或真人口语后 | 想说但说不出的——这是最高优先级的词，因为它们是我**确实需要**的 |
| **阅读和写作**（第 05 篇） | 读长文查词时；LLM 批改指出用词不准时 | 查过两次的词；批改给出的「母语者会用的词」 |

第二类要特别说一下：每次口语练习后花 2 分钟回想「刚才哪里卡了、想说什么」，把中文写下来，晚上查出英文做成卡。这些卡的记忆效果远好于任何词表——因为你已经在需要它的时候痛过一次。

### 2. 流程

```
遇到 → 记一个音或中文（碎片时间，5 秒）
      → 晚上 5 分钟：查、写句子、进 Anki（每天 3–5 张，不多）
      → 午饭 10 分钟复习
      → 三天内主动用一次（说给 AI 听、写进本周的邮件练习、跟老师聊时用上）
```

最后一步——三天内用一次——是从「认识」到「会用」的那一步。不做这一步，句子卡也只是更好的单词卡。

### 3. 每天几张

**3–5 张新卡**，不多。这个数字是复习量倒推的：Anki 的间隔算法下，每天 5 张新卡半年后每天的复习量约 40–60 张，10 分钟正好。每天 20 张新卡的话，两个月后每天复习 200 张，午饭做不完，积压，然后放弃——这是我前几次用 Anki 失败的原因。

一年 5 张 × 300 天 = 1,500 张。听起来不多，但这 1,500 个词是从我自己的输入和卡壳里捞出来的，每个都是我需要的。加上泛听里被动吸收的，一年后 Oxford 5000 抽样的「不认识」从 25 到 0 是现实的。


## 五、按场景建表

从输入里捞词是主流程，但生活词有一个问题：**在国内的输入里遇不到**。我在国内不会听到 `security deposit`、`urgent care`、`routing number`。所以生活词要主动补，按场景，每周一个。

方法：选一个场景，让 LLM 生成「这个场景里一个母语者会遇到的 30 个词和短语，每个带一个真实对话里会出现的句子」，然后**我自己筛**——已经会的删掉，剩下的每天挑 2–3 个进卡（占每天 3–5 张里的一部分）。不要一次把 30 个全加。

场景清单（第 07 篇会展开每个场景的对话流程，这里只列词汇维度）：

| 周 | 场景 | 词汇维度举例 |
|---|---|---|
| 1 | 租房 | lease, deposit, landlord / tenant, utilities, furnished, notice period, move-in inspection |
| 2 | 看病 | appointment, GP / family doctor, symptoms（sore, swollen, dizzy, nauseous）, prescription, over the counter, pharmacy, insurance / co-pay |
| 3 | 银行 | checking / savings account, routing number / sort code / BSB, direct debit, wire transfer, statement, overdraft |
| 4 | 超市和厨房 | produce, aisle, checkout, receipt, 各种厨具和食材 |
| 5 | 交通 | commute, transit pass, fare, lane, license, registration, insurance, parking permit |
| 6 | 政府和办事 | ID, SSN / SIN / NI number, tax file, appointment, form, notarize, proof of address |
| 7 | 餐厅和社交 | reservation, split the bill, tip, allergy, small talk 的一套套话 |
| 8 | 工作制度 | payroll, PTO, benefits, 401k / pension, performance review, onboarding |

八周一轮，之后从头再来一轮——第二轮会发现第一轮加的卡已经会了，能加更细的。

注意各国用词不同（美 `apartment` / 英 `flat`，美 `checking account` / 英 `current account`，美 `routing number` / 英 `sort code` / 澳 `BSB`）。没定国家之前两套都认识就行，定了之后主用一套。


## 六、Anki 设置与每日节奏

### 1. 设置

- 一个牌组，不分类。分类会增加管理成本，而且一个词属于哪个场景常常不清楚。用标签（`#work` `#life` `#listen` `#stuck`）代替，需要时按标签筛。
- 每日新卡上限：5。复习上限：100（正常情况用不到，断了几天后避免被几百张吓退）。
- 卡片模板：正面句子挖空，背面全部。Anki 自带的 Cloze 类型就够。
- 手机端：AnkiDroid（免费）/ AnkiMobile（付费一次）。同步用 AnkiWeb，免费。
- 不下载别人的牌组。别人的句子没有我的情境。

### 2. 每日节奏

| 时段 | 做什么 | 时长 |
|---|---|---|
| 碎片时间 | 遇到词记一个音或中文（手机备忘录一行） | 秒 |
| 午饭 | 复习到期卡 | 10 min |
| 晚上 30 分钟的前 5 分钟 | 备忘录里的词查、写句子、进 Anki，3–5 张 | 5 min |
| 一周 | 一个生活场景，从 LLM 生成的 30 个里筛，分散进每天的 3–5 张 | — |

复习时的一个规则：**答不出就直接看背面，不要想超过 5 秒**。Anki 的价值在重复次数，不在每次想多久。


## 七、常见卡点

| 卡点 | 处理 |
|---|---|
| 到期卡越积越多 | 新卡加多了。停加新卡一周，只复习；然后新卡降到 3 |
| 卡片答对了但说话时还是想不起 | 缺「三天内用一次」那步。把这类词标 `#stuck`，周六和老师聊时专门用 |
| 生活词场景清单加了但没情境，记不住 | 让 LLM 生成的句子里放入我的情境（「我在悉尼租一套一居室」），或者用 YouTube 上那个场景的真实 vlog 当听力材料，从里面捞 |
| 同一个词在不同句子里加了三张 | 正常，不同用法就是不同的卡。但同一用法重复了就删 |
| 复习变成机械翻卡，不走心 | 复习时**读出声**。多一个通道，也顺便练嘴 |


## 八、本文小结

- 六级词汇偏学术，缺口在家居身体、办事制度、短语动词、「认识不会用」和语气词，后两类对口语流畅度影响最大。
- 唯一的核心方法：句子卡——自己遇到的完整句子挖空，背面词 + 一行解释 + 来源 + 自己写的句子。
- 词从三处捞：听力错误、口语卡壳（最高优先级）、阅读查词和批改；流程是记音 → 晚上做卡 → 午饭复习 → **三天内用一次**。
- 每天 3–5 张新卡，由 10 分钟复习量倒推；一年约 1,500 张。
- 生活词在国内遇不到，按场景每周一个主动补，LLM 生成候选、自己筛，各国用词并存。
