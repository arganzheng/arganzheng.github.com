我对自己英语的判断一直是「六级，还行」。直到有一次开跨国会议，对方一个语速正常的澳洲工程师讲了三分钟，我只听懂了主题，没听懂结论。会后我意识到「还行」这个判断没有任何依据——我从来没有量过。

这一篇做的事很朴素：在开始练之前，先给四项能力各定一个**可以重复测的数字**。不为了打击自己，而是因为后面十二个月里「有没有进步」这个问题，只有对着数字才能回答。方法必须免费或很便宜、一小时内做完、每个月能重来一次。


## 一、为什么先量

这一篇按「一项能力一个测法」组织，每个测法都要满足三个条件：能自己做、结果是数字、下个月重做时条件一致。这三个条件排除了很多看起来更「权威」的选项，比如真的去考一次 IELTS——两千多块、结果要等、一年只舍得考一两次，不适合当月度仪表盘。

六级为什么不能直接当基线：它是五年前甚至十年前的成绩，而且只有一个总分。CET 从设计上就是读写权重大、听力是录音棚慢速、没有口语（口语是另一门选考）。它告诉我「B2 下沿附近」，但不告诉我听力和口语分别在哪——而这两项恰恰是我最需要知道的。

| 章 | 测什么 | 用什么 | 产出的数字 |
|---|---|---|---|
| 二 | 综合定级 | 免费的 CEFR 定级测试 | CEFR 等级 |
| 三 | 听力 | 一段真实语速音频的听写 | 正确率 % |
| 四 | 口语 | 两分钟录音自评 | 停顿次数、语法错次数、词汇重复 |
| 五 | 词汇 | 词汇量估算 + Oxford 5000 抽样 | 词汇量、生活词覆盖率 |
| 六 | 读写 | 掐表阅读 + 250 字作文 LLM 批改 | 阅读速度、中式表达条数 |
| 七 | 考试标尺 | IELTS 官方样题掐表 | 估分 |
| 八 | 基线表 | 汇总 | 一张表 |


## 二、综合定级：先拿一个 CEFR 等级

免费的定级测试主要有两个：EF 的 [EF SET](https://www.efset.org/)（50 分钟，听力 + 阅读，出 CEFR 等级和 0–100 分）和剑桥官网的 [General English test](https://www.cambridgeenglish.org/test-your-english/)（25 题，只给一个大致等级）。两个都不测口语和写作，所以它们给出的等级是**读听的上限**，实际综合水平只会更低。

我的做法：做 EF SET 50 分钟版，记下听力和阅读的分项。它的意义不是精确，而是把「六级」翻译成一个国际通用的坐标，方便之后和考试要求、招聘 JD 里的「fluent」「professional working proficiency」对得上。

一个坑：这类测试可以无限重考，重考会因为熟悉题型而虚高。每月重测用同一个测试没问题，但别在一天里考两次取高分。


## 三、听力：听写一段真实语速

这是四项里最需要「用数字取代感觉」的一项，因为「听懂了」的感觉极不可靠——听新闻时大脑会用上下文把没听清的地方自动补上，让人觉得听懂了 90%，其实抓住的词只有 60%。

### 1. 选一段材料

条件：母语者、正常语速、没有为学习者放慢、有官方文本可以对照、2 分钟左右。我用的是 NPR 的新闻简报（[NPR News Now](https://www.npr.org/podcasts/500005/npr-news-now)，每小时更新，5 分钟，有 transcript）截前 2 分钟。要英式口音可以用 BBC 的 Global News Podcast，但它没有逐字文本，对照麻烦。

关键是**每月用同一来源、不同日期**的材料，难度可比，又不会因为记得内容而虚高。

### 2. 听写

每句最多听三遍，写下听到的每个词，听不出来的留空。不查词典，不看文本。2 分钟的新闻大约 300 词，听写用时 20–30 分钟。

### 3. 算分

对照 transcript，数出**写对的词数 / 总词数**。冠词、复数、时态错算错，拼写错但显然听对了的算对。然后再数一遍，把错的分成三类：

| 错误类型 | 表现 | 说明的问题 |
|---|---|---|
| 听到了但不认识 | 能写出近似拼写，查了词典才知道意思 | 词汇缺口 |
| 认识但没听出来 | 看到文本「啊原来是这个词」 | 连读、弱读、语速——这是六级学习者最大的一类 |
| 整句没抓住 | 一段空白 | 语速 + 背景知识 |

第一次做完我的数字是：正确率 68%，错误里「认识但没听出来」占了一半以上。这一个数字比六级听力那个分数有用得多——它直接告诉我第 02 篇该主攻什么。


## 四、口语：两分钟录音自评

口语最难自测，因为没有对照文本。但有两个指标不需要评委也能数：**停顿**和**重复**。

### 1. 录音

手机录音，两个题目各两分钟，不准备、不打草稿：

- 「介绍你最近做的一个项目，它解决什么问题、你负责哪部分、遇到过什么困难」（工作场景）
- 「描述你住的地方，以及你周末通常怎么过」（生活场景）

两个题目一个是熟悉领域、一个是生活领域，差距通常很明显——我讲项目能撑满两分钟，讲周末 40 秒就没话了，不是没有事情可说，是没有词。

### 2. 数

回放，数三个数字：

| 指标 | 怎么数 | 我的第一次 |
|---|---|---|
| 长停顿 | 停顿超过 3 秒的次数 | 项目 6 次，周末 11 次 |
| 语法错 | 时态、单复数、主谓一致、冠词——听自己的录音很容易听出来 | 各 5 次左右 |
| 词汇重复 | 同一个内容词（`good`、`thing`、`do`、`very`）出现 5 次以上的个数 | 4 个 |
| 时长 | 讲了多久停下 | 2:00 / 0:45 |

再做一件事：把录音丢给 LLM 转写，让它列出「一个母语工程师会怎么说这段话」——不是为了打分，而是为了看到差距的**形态**：我用了 15 个词说的事情它用 8 个词，我用 `very important` 它用 `critical`，我三个短句它一个带从句的长句。这些形态第 04 篇要用。


## 五、词汇：估算总量 + 抽样生活词

### 1. 总量

[testyourvocab.com](https://testyourvocab.com/) 通过两轮勾选估算词汇量，5 分钟。它的数字偏乐观（认识 ≠ 会用），但用作月度趋势足够。六级学习者的典型区间是 7,000–10,000。

### 2. 生活词覆盖率

总量不说明问题，我的词汇是偏科的：`idempotent`、`throughput` 都认识，`colander`（滤锅）、`co-pay`（医保自付）不认识。所以再做一个抽样：从 [Oxford 5000](https://www.oxfordlearnersdictionaries.com/wordlists/oxford3000-5000) 的 B2–C1 部分随机抽 100 个词，标出三种状态——会用 / 认识 / 不认识。这 100 个词记下来，每月用**同一份**重测，覆盖率的变化就是第 03 篇的验收指标。

第一次抽样我的结果：会用 48、认识 27、不认识 25。「认识但不会用」那 27 个是最值得练的——它们离会用只差几次使用。


## 六、读写：速度与中式表达

### 1. 阅读

阅读是我最强的一项，但强在技术文档。测法：一篇 The Guardian 或 BBC 的长篇报道（约 1,500 词，避开我熟悉的科技话题），掐表读完，然后用自己的话写三句概括。记录：**词/分钟**和有没有抓住主旨。母语者的阅读速度在 200–300 词/分钟，六级学习者读非专业文本大约 100–150。

### 2. 写作

限时 40 分钟写一篇 250 字的议论文，题目用 IELTS Task 2 的真题（网上很多，选一个社会话题而非科技话题）。写完丢给 LLM，prompt 大意是：

> 你是英语写作老师。不要重写这篇文章。列出：(1) 语法错误，(2) 用词不准确的地方，(3) 一个母语者不会这样表达的句子（中式英语），每条给出修改建议。最后按 IELTS Task 2 的四个评分维度各给一个分数并说明理由。

数三个数字：语法错条数、中式表达条数、LLM 估分。LLM 的 IELTS 估分不可靠（通常偏高 0.5–1 分），但中式表达的条数是一个很好的进步指标，我第一次是 9 条。这个 prompt 在第 05 篇会细化。


## 七、考试标尺：IELTS 样题掐表

前面六节量的是能力，这一节量的是「翻译成分数大概是多少」。IELTS 官网有[免费样题](https://ielts.org/take-a-test/preparation-resources/sample-test-questions)，做一套听力（30 分钟）和阅读（60 分钟），对答案，用官方的分数换算表得出两个分项估分；口语和写作用前面第四、六节的结果参照评分标准估。

这要花一个半小时，不必每月做——每季度末做一次。它的作用是校准：如果四项自测都在进步而模考分数不动，说明能力和题型之间有 gap，是第 08 篇要解决的问题。

选 IELTS 而不是 TOEFL 做标尺，只是因为它的免费材料最多、分数最常被拿来对标 CEFR、绝大多数国家都认。真正考哪门是第 08 篇的事。


## 八、基线表

把上面所有数字放进一张表。这张表是整个系列的仪表盘，之后每月重测一次、每季度加一列：

| 项 | 指标 | 起点（M0） | M1 | M2 | M3 | … | 12 个月目标 |
|---|---|---|---|---|---|---|---|
| 综合 | EF SET 等级 / 分 | B2 / 58 | | | | | C1 / ≥ 71 |
| 听力 | NPR 2 分钟听写正确率 | 68% | | | | | ≥ 90% |
| 听力 | 「认识但没听出来」占错误的比例 | 55% | | | | | ≤ 20% |
| 口语 | 项目题 > 3 秒停顿 / 语法错 | 6 / 5 | | | | | ≤ 2 / ≤ 1 |
| 口语 | 生活题时长 / > 3 秒停顿 | 0:45 / 11 | | | | | 2:00 / ≤ 2 |
| 词汇 | testyourvocab | 8,400 | | | | | ≥ 12,000 |
| 词汇 | Oxford 5000 抽样：会用 / 认识 / 不认识 | 48 / 27 / 25 | | | | | ≥ 85 / ≤ 15 / 0 |
| 阅读 | 非专业长文 词/分钟 | 120 | | | | | ≥ 200 |
| 写作 | 250 字：语法错 / 中式表达 | 6 / 9 | | | | | ≤ 2 / ≤ 2 |
| 考试 | IELTS 样题 听 / 读（每季度） | 6.0 / 6.5 | | | | | ≥ 7.0 / ≥ 7.5 |

表里的起点是我的实测。几个观察：阅读和综合定级确实在 B2，但听力和口语明显落后——尤其生活题的口语，45 秒就说不下去了，这和我对自己「六级还行」的印象差得很远。这张表定下了后面的顺序：Q1 听力、Q2 口语，不是拍脑袋，是数字。

重测规则：每月最后一个周末，一小时，做第二到第六节（第七节每季度）。材料换日期不换来源，题目换一个不换类型。把数字填进表，不解释、不找理由，下一篇再说怎么改计划。


## 九、本文小结

- 六级只说明读写在 B2 下沿，听说需要单独量。
- 每项能力一个数字：听写正确率、录音里的停顿数、词汇量 + 生活词抽样覆盖率、阅读速度、作文里的中式表达条数、季度一次的 IELTS 样题估分。
- 听写错误分成三类，「认识但没听出来」的比例决定听力该怎么练。
- 口语用两个题目——熟悉领域和生活领域——差距本身就是信息。
- 所有数字进一张基线表，每月同来源、不同材料重测。
