# 粘贴博客 Markdown（上传图片）

这是给作者使用的 Chrome MV3 扩展：把博客 Markdown 中指向
`arganzheng.life` 的图片下载成文件，再按顺序粘贴到目标编辑器，让编辑器用自己的粘贴上传流程处理图片。

## 安装

1. 打开 `chrome://extensions`，开启「开发者模式」。
2. 点「加载已解压的扩展程序」。
3. 选择本目录 `tools/md-paste-extension/`。

## 使用

请在博客文章的「导出」菜单点「复制 Markdown」（不要选「复制富文本（带图片）」），然后在公司编辑器的源码编辑区放置光标。右键选择「粘贴博客 Markdown（上传图片）」，或按 `Alt+Shift+V`；也可以点击扩展工具栏图标。上传期间会逐张显示进度，结束后报告已上传、未确认和保留外链的数量。

扩展会先尝试模拟粘贴和拖放，并根据编辑器内容变化判断图片是否已接收；如果编辑器只接受可信的系统粘贴事件，会暂时把剪贴板替换成图片逐张粘贴，完成后尽力恢复原来的 Markdown。保留外链时，提示的第二行会区分下载失败、浏览器不允许插件粘贴、编辑器没有接收和非博客图片，并给出可用的首个错误原因。

如果剪贴板检测到富文本图片而 Markdown 中没有图片链接，会提示「剪贴板里是富文本，图片不在 Markdown 里。请在博客导出菜单点『复制 Markdown』后再试。」没有图片链接的 Markdown 文本会正常粘贴，并提示「已粘贴 N 字，里面没有博客图片链接……」。

## 限制

- 只下载 `arganzheng.life` 上的 HTTP(S) 图片；其他主机的图片 Markdown 会原样保留。
- 普通站内链接会改成根相对路径；代码中的链接、裸 URL、自动链接和其他主机链接保持不变。
- 引用式图片（例如 `![说明][image-id]`）不会转换。
- 图片是否上传成功取决于目标编辑器是否接受粘贴/拖放的图片文件，并由它自己的上传流程确认。
- 代码围栏和反引号代码中的图片不会转换。

本目录没有构建步骤或运行时依赖。Node 解析器测试在 `test/split.test.cjs`；Playwright 端到端 harness 在 `test/harness/`。
