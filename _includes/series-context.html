{%- comment -%} Sets, for a post with `series:` in its front matter: series_meta the entry from _data/series.yml (name, overview) series_posts members ordered by date (oldest first) series_index 1-based position of the current post series_total member count series_prev / series_next neighbouring posts (nil at the ends) and, for a page that *is* a series overview (it has no `series:` of its own): overview_meta the site.data.series entry whose `overview` == page.url Include once before series-nav.html / roadmap-box.html / series-toc.html / series-side.html / the pager. {%- endcomment -%} {%- assign series_meta = nil -%} {%- if page.series -%} {%- assign series_meta = site.data.series[page.series] -%} {%- assign series_posts = site.posts | where: "series", page.series | sort: "date" -%} {%- assign series_total = series_posts | size -%} {%- assign series_index = 0 -%} {%- assign series_prev = nil -%} {%- assign series_next = nil -%} {%- for p in series_posts -%} {%- if p.url == page.url -%} {%- assign series_index = forloop.index -%} {%- unless forloop.first -%}{%- assign prev_i = forloop.index0 | minus: 1 -%}{%- assign series_prev = series_posts[prev_i] -%}{%- endunless -%} {%- unless forloop.last -%}{%- assign series_next = series_posts[forloop.index] -%}{%- endunless -%} {%- endif -%} {%- endfor -%} {%- endif -%} {%- assign overview_meta = nil -%} {%- unless page.series -%} {%- for oc_entry in site.data.series -%} {%- if oc_entry[1].overview == page.url -%}{%- assign overview_meta = oc_entry[1] -%}{%- endif -%} {%- endfor -%} {%- endunless -%}
