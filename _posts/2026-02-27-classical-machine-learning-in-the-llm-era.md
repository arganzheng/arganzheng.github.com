## 内容简介

《LLM 时代的经典机器学习：只讲它在哪里重现》是一组共六篇的系列文章，对应[《AI 算法工程师学习地图》](/ai-algorithm-engineer-learning-roadmap.html)的第 L2 层（机器学习基础）。它面向读完 [L0 数学](/math-for-ai-algorithm-engineers.html)与 [L1 工具箱](/tooling-for-ai-algorithm-engineers.html)、准备进入深度学习与 LLM 的读者，讲的是**经典机器学习里那些在大模型时代仍然每天在用的概念——它们是什么、在 LLM 工作里以什么形态重现、以及一个能算出来的数字**。

它回答的问题是：

> **LLM 工作里的哪些问题其实是经典机器学习的老问题？它们的经典解法在 LLM 上还成立吗？**

"经典机器学习"——线性模型、SVM、决策树、K-Means、交叉验证——在大模型时代最常被跳过。理由听起来成立：今天没有人用 SVM 做 NLP 了，Transformer 也不需要特征工程。但跳过它的人会在 L5 遇到一组熟悉的麻烦：奖励模型训了两个 epoch 之后 RL 开始"钻空子"；benchmark 上涨了 5 个点结果发现测试题在训练数据里；judge 模型给长回答打高分；数据过滤器把某一类文本全滤掉了。这些问题在经典机器学习里各有一个名字——过拟合、测试集泄漏、评估偏差、分类器的类别不平衡——并且有一套成熟的处理方法。

所以这一层的价值不在"模型"而在**方法论**。本系列不按教科书的顺序复述算法，而是反过来：把 LLM 工作里实际出现的经典机器学习列出来，每一处从概念本身讲起（假设读者没学过），说明它在 LLM 上的重现、要懂到什么程度、以及一个用 scikit-learn 几十行就能跑出来的数字。

举一个例子说明这个系列的取法。"奖励模型会过拟合、导致 reward hacking"是 L5 里一句常见的话；本系列第一篇先用 30 个点拟合一条正弦曲线把**过拟合**本身画出来（多项式次数从 1 到 25，训练误差一路降、验证误差在次数 15 之后飙升），再讲奖励模型为什么是过拟合的典型（8B 参数的特征提取器 + 几万对偏好数据），最后指出经典解法——更多数据、正则化（RLHF 的 KL 项）、早停、集成——每一条在 L5 里的对应物。第二篇再用逻辑回归拟合一个 Bradley-Terry 模型，看到"奖励模型的 loss 就是逻辑回归的 loss 作用在分差上"。

系列覆盖的范围可以概括为一张"重现表"：

| 经典概念 | 在 LLM 工作里的重现 | 在哪一篇 |
|---|---|---|
| 训练 / 验证 / 测试集划分、测试集泄漏 | benchmark 污染：测试题混进预训练语料；在同一 benchmark 上反复调参 | 第一篇 |
| 过拟合与欠拟合 | 奖励模型过拟合 → reward hacking；SFT 多 epoch 后的记忆 | 第一篇 |
| 偏差 - 方差权衡、集成 | 多次采样投票（self-consistency）、多个 judge 取平均、模型融合（model soup） | 第一篇 |
| 正则化 | weight decay、dropout、RLHF 里的 KL 惩罚（把参考模型当先验） | 第一篇 |
| 线性回归、Ridge / Lasso | weight decay 就是 Ridge；Lasso 的稀疏 | 第二篇 |
| 逻辑回归 | 奖励模型 = 特征提取器（LLM）+ 逻辑回归头；Bradley-Terry 的 loss 就是它 | 第二篇 |
| 分类器 | 预训练数据的质量过滤器、安全分类器、路由器；为什么用小模型 | 第三篇 |
| 梯度提升树 | 表格数据仍是首选；数据质量打分的特征模型 | 第三篇 |

十五行里没有一行需要 SVM 的对偶推导或决策树的分裂准则；每一行需要的是**概念本身与它的失效方式**。这决定了本系列的深度标准。


## 为什么写这个系列？

### 这一层原来是一篇导读，读者需要从概念讲起

这个系列的前身是一篇导读，假设读者已经学过经典机器学习，只回答"哪些今天还在用、在哪里重现"。对从零开始的读者，它是一堆没有解释的名词。展开成系列之后，每个概念都从定义与一个能跑的例子讲起，再讲它在 LLM 上的形态。

### 方法论比模型活得久

SVM 与 LDA 退场了，但"测试集只能看一次"、"参数远多于样本时会过拟合"、"准确率在类别不平衡时会骗人"、"两个模型的差异要看置信区间"没有退场——它们在 LLM 上以更大的规模重现，而且因为规模大，犯错的代价也更大：一次污染的评测能误导一个团队几个月，一个过拟合的奖励模型能让几千 GPU 小时的 RL 白跑。

### 现有材料的断层

- **经典教材**（Bishop、ESL）与**课程**（CS229）按模型组织，篇幅大半在今天不用的方法上，且不对到 LLM；
- **实践书**（Géron 的 Hands-On ML）把 scikit-learn 用得很好，但停在表格数据与图像分类，没有奖励模型、benchmark 污染、去重；
- **LLM 的论文与博客**假设读者会这些概念，一句"reward hacking 本质是过拟合"带过。

本系列取中间那段路：概念从零讲、用 scikit-learn 跑出来、对到 LLM 上，六篇加起来大约一本教材两章的篇幅。


## 适合哪些读者？

### 从零开始、准备进 L3 的读者

你读完了 L0 与 L1，还没学过任何机器学习。本系列是"什么是学习"的第一课：过拟合、泛化、评估这些概念在这里第一次出现，之后 L3 的深度网络、L5 的后训练都在用它们。

### 直接从 LLM 入门、跳过了经典部分的工程师

你在做 SFT / RLHF / 评测，遇到过 reward hacking、benchmark 分数不可信、judge 偏好长回答。本系列告诉你这些问题的经典名字与经典解法——叫出名字，解法就在手边。

### 做数据工程的人

预训练数据的质量过滤、去重、配比、多样性分析，每一件都是经典机器学习在万亿 token 上的工程化。第三、四、五篇直接对应。

### 要做评测、要读实验结果的人

第六篇讲评估的全部工具：混淆矩阵、阈值权衡、AUC、校准、交叉验证、配对检验、多重比较——以及每一个在 LLM 评测里的陷阱。


## 系列的整体主线

六篇按"先懂什么是学习与泛化，再看两类监督模型，再看无监督的三个工具，最后讲怎么评估"的顺序推进：

```text
第一篇：什么是学习 —— 划分、过拟合与欠拟合、偏差-方差、正则化；benchmark 污染与 reward hacking
        ↓
第二篇：线性回归与逻辑回归 —— 最小二乘、Ridge / Lasso、sigmoid 与交叉熵；奖励模型 = 逻辑回归作用在分差上
        ↓
第三篇：分类器一家 —— 朴素贝叶斯、KNN、SVM、决策树 → 随机森林 → 梯度提升；数据质量分类器为什么用小模型
        ↓
第四篇：无监督 —— K-Means 与 k 的选择、DBSCAN、PCA；语料的多样性分析与 embedding 可视化
        ↓
第五篇：去重 —— Jaccard、MinHash 的无偏估计、LSH 的 S 曲线；FineWeb 的 b = 14, r = 8 是怎么定的
        ↓
第六篇：评估 —— 混淆矩阵、阈值、AUC、类别不平衡、校准、交叉验证、配对检验、多重比较；judge 的偏差
```

第一篇是**方法论的底座**：什么是泛化、为什么会过拟合、误差从哪来。第二、三篇是**监督学习**：从最简单的线性模型到树模型，以及它们在 LLM 数据管线与奖励模型里的位置。第四、五篇是**无监督学习**：不需要标签的三件事——聚类、降维、去重。第六篇是**评估**：一切结论是否成立的最后一道关。

三条交织的线索：

```text
概念线：泛化 → 过拟合 → 正则化 → 线性模型 → 分类器 → 聚类 / 降维 → 相似度估计 → 评估指标
数字线：次数 15 验证误差飙升 · Lasso 45/50 系数为零 · 8B 打分 = 训练算力的 1/3 · 29 维解释 95% · b=14, r=8 阈值 0.685 · 500 题配对 z=3.1
LLM 线：benchmark 污染 → reward hacking → 奖励模型 → 质量过滤器 → 数据配比 → 万亿 token 去重 → judge 偏差与多重比较
```

每一篇都用同样的方法：**从概念的定义讲起，用几十行 scikit-learn 跑出一个数字，指出它在 LLM 工作里的形态与失效方式**。


## 章节结构与分章导读

### 1. 什么是学习：划分、泛化、过拟合与偏差-方差

第一篇建立整个系列——也是整个算法地图——最基础的概念：**泛化**。

这一篇会覆盖：

- 学习的定义：从有限样本推断没见过的样本；训练误差与泛化误差的差别；
- 训练 / 验证 / 测试三份数据各干什么，测试集为什么只能看一次；
- 过拟合与欠拟合：用 30 个点拟合正弦曲线，多项式次数从 1 扫到 25，画出训练误差与验证误差的剪刀差；不可约误差是下限；
- 测试集泄漏：在测试集上选超参数之后分数偏乐观多少（200 次重复的数字）；**benchmark 污染**与"在同一个 benchmark 上反复调参"是它在 LLM 上的两种形态；
- 偏差-方差分解：低次模型偏差大、高次模型方差大；集成只降方差——self-consistency、judge 平均、model soup 都是集成；多 seed 结果差异大的理论依据；
- 正则化：任何把模型拉向简单解的项——weight decay、dropout、早停、RLHF 的 KL 惩罚、LoRA 的低秩约束；
- **reward hacking 本质是在一个过拟合的评估器上做优化**，经典解法逐条对应。

核心问题是：

> **benchmark 涨了 5 个点，怎么知道不是测试题泄漏？奖励模型的准确率 80%，为什么 RL 还会钻空子？**

### 2. 线性回归与逻辑回归：奖励模型的骨架

第二篇讲两个最简单的模型，它们是后面一切的原型。

这一篇会覆盖：

- 线性回归：最小二乘的闭式解 $$(X^T X)^{-1} X^T y$$ 与梯度下降得到同一个答案（差 $$10^{-14}$$）；
- Ridge（$$L_2$$）与 Lasso（$$L_1$$）：50 个特征只有 5 个有用时，Ridge 把所有系数压小、Lasso 把 45 个压到恰好为零；Ridge 就是 weight decay；
- 逻辑回归：$$\sigma(w^T x + b)$$ 与交叉熵——L0 第五、六篇的模板；它是**每一个神经网络分类头**的原型；
- 奖励模型 = LLM 特征提取器 + 逻辑回归头：Bradley-Terry 的 $$-\log\sigma(r_w - r_l)$$ 就是逻辑回归作用在**两个样本的特征差**上——用 3000 个偏好对拟合出来，留出集准确率 91.5%，与用真实分数判断的上限 91.3% 持平：**奖励模型的准确率上限是标注的一致性**；
- 朴素贝叶斯、感知机、SVM 的一句话定位。

核心问题是：

> **奖励模型和逻辑回归是什么关系？为什么它的准确率到 80% 就上不去了？**

### 3. 分类器一家：从朴素贝叶斯到梯度提升

第三篇把六个经典分类器放在同一份数据上比一比，然后讲它们在 LLM 数据管线里的位置。

这一篇会覆盖：

- 六个分类器各一句话：逻辑回归（线性边界）、朴素贝叶斯（特征独立假设）、KNN（不训练、找邻居投票）、SVM（核把边界变弯）、决策树（训练 100%、测试掉一截）、随机森林（bagging 降方差）、梯度提升（逐棵树拟合残差）；同一份 5000 样本的表格数据上的准确率与耗时；
- 树模型的特征重要性：前 6 个特征占 91%——数据质量打分里"困惑度、长度、符号比例哪个在起作用"；
- **数据质量分类器为什么用小模型**：给 15T token 打分，用 8B 模型是训练算力的 1/3，1 亿参数的模型是 0.4%，线性模型几乎为零——两级做法：大模型标几十万段、小分类器过全部；FineWeb-Edu 与 DCLM 的做法；
- 小分类器带回来的经典问题：分布偏移、对少数语体的系统性误杀、阈值；
- KNN 以"检索"的形式无处不在：距离度量、维度灾难、近似最近邻。

核心问题是：

> **预训练数据过滤为什么用 fastText 与线性模型而不是 LLM？表格数据为什么至今是 GBDT 的天下？**

### 4. 无监督：K-Means、PCA 与 embedding 聚类

第四篇讲不需要标签的两件事：聚类与降维。

这一篇会覆盖：

- K-Means：算法、$$k$$ 怎么选（簇内平方和的肘部、轮廓系数）、它假设簇是球形等大的；
- DBSCAN：按密度聚、不用指定 $$k$$、能标出离群点；两个月牙上 K-Means 的 ARI 0.26 vs DBSCAN 的 1.0；
- 聚类在数据工程里的用法：语料 embedding 后聚类 → 每簇抽几条看主题 → 按簇配比 / 找垃圾簇 / SFT 数据保多样性；
- PCA：协方差矩阵的特征向量（L0 第三篇）；手写数字 64 维里 29 维解释 95% 的方差——数据"基本上"是低维的，与 LoRA 的低秩假设是同一种直觉；
- 与 SVD 的关系：协方差的特征值 = 奇异值² / (n − 1)，两种算法给出相同的数字；
- 二维可视化：PCA 是第一步，t-SNE / UMAP 更好但非线性、不可逆；embedding 空间的各向异性。

核心问题是：

> **怎么知道一个语料里有什么主题？4096 维的 embedding 怎么"看"？**

### 5. 去重：MinHash 与 LSH 的概率

第五篇把 L4 数据工程必用的一个算法的概率算清楚。

这一篇会覆盖：

- 精确去重只能抓完全一样的副本；近似去重要处理"大部分一样"的文本；
- Jaccard 相似度：两个 n-gram 集合的交并比；
- MinHash：随机 hash 取最小值，两个集合最小值相等的概率恰好等于 Jaccard——一行证明；$$k$$ 个 hash 的估计标准差 $$\sqrt{J(1 - J)/k}$$，$$k = 16 / 128 / 1024$$ 的实际数字；
- LSH：$$k$$ 个签名分 $$b$$ 组每组 $$r$$ 个，任一组全等即候选，$$P = 1 - (1 - s^r)^b$$ 是一条 S 曲线；FineWeb 的 $$b = 14, r = 8$$ 在 $$s \approx 0.685$$ 处过 50%——"Jaccard 大于约 0.7 视为重复"的来源；$$r$$ 大更严、$$b$$ 大更松；
- 在 2000 段文本上跑一遍：两两比较要算 200 万对，LSH 只产生 267 个候选；漏掉的都是 Jaccard 低于阈值的；
- 三个经典元素——集合相似度、随机化估计、用概率分桶换掉 $$O(n^2)$$——没有它 15T token 的去重寸步难行。

核心问题是：

> **两段文本"相似"到什么程度算重复？MinHash 的阈值怎么定？**

### 6. 评估：从混淆矩阵到 judge 的一致性

第六篇讲一切结论是否成立的最后一道关。

这一篇会覆盖：

- 混淆矩阵的四个数与派生指标：准确率、精确率、召回率、F1、AUC——各回答什么问题，各在 LLM 上对应什么（过滤器的漏放与误杀、污染检测的召回）；
- 阈值控制精确率与召回率的权衡：同一个分类器阈值从 0.1 到 0.9 的表；要求召回 ≥ 95% 时精确率掉到多少；FineWeb-Edu 切 3 分还是 2 分是同一种取舍；
- 类别不平衡：正例 3% 时"全判负"准确率 95.6%，逻辑回归阈值 0.5 准确率 95.9% 但召回只有 10%——不平衡时看 P / R / AUC；
- 校准：说 80% 的时候是不是十次里八次对；ECE；逻辑回归天然校准好、树模型与 SVM 要校准；RLHF 之后模型的校准变差；
- 奖励模型的评估是准确率、judge 的评估是一致性；位置 / 长度 / 自我偏好是系统误差，集成消不掉；
- 交叉验证：300 条数据上单次划分抖 8 个点，5 折稳到 ±2；
- 配对检验：500 题上差 4 个点，独立比较 z = 1.4 不显著、McNemar z = 3.1 显著；
- 多重比较：两个一模一样的模型在 20 个 benchmark 上有 61% 的概率至少一个"显著"不同。

核心问题是：

> **过滤器"准确率 95%"是什么意思？judge 与人类"一致率 80%"够不够？"20 个 benchmark 领先 12 个"算不算？**


## 贯穿全系列的实践线

本系列每一篇配一个 scikit-learn 脚本，全部用自带的小数据集或合成数据、CPU 上十几秒跑完，在 [ai-learning-labs/classical-ml](https://github.com/arganzheng/ai-learning-labs/tree/main/classical-ml)：

```text
第一篇    多项式次数扫描画出过拟合；在测试集上选超参数的乐观偏差；偏差-方差分解与 bagging
第二篇    闭式解 vs 梯度下降；Ridge / Lasso 的系数；乳腺癌数据的逻辑回归；用逻辑回归拟合一个 Bradley-Terry 奖励模型
第三篇    六个分类器同一份数据上比；梯度提升的特征重要性；给 15T token 打分的算力账
第四篇    K-Means 扫 k；DBSCAN vs K-Means；PCA 的解释方差、与 SVD 对数、二维图
第五篇    MinHash 估计 vs 真实 Jaccard；S 曲线表；2000 段文本的 LSH 去重
第六篇    阈值表；不平衡；校准与 ECE；交叉验证；McNemar；多重比较的模拟
```

六个脚本跑完、改过参数，L2 就够了。其中第二篇的奖励模型与第六篇的配对检验最值得改着玩：前者把"奖励模型会过拟合、上限是标注一致性"从一句话变成自己看到的数字，后者把"差 3 个点算不算"变成一个能算的问题。

## 本系列的边界

- **不推导**：SVM 的对偶、EM 算法的收敛、决策树的分裂准则、核方法、PAC 学习理论。它们是很好的数学练习，但不在最小集里；想看严格版本翻 Bishop 或 ESL。
- **深度学习**：神经网络、反向传播、优化器、正则化在深度网络里的具体形态。在 L3 系列。本系列只到"逻辑回归是分类头的原型"。
- **后训练算法本身**：奖励模型怎么训、RLHF 怎么做、DPO 是什么。在 L5 系列。本系列只到"奖励模型是逻辑回归、会过拟合、上限是标注一致性"。
- **数据工程的流水线**：怎么抓、怎么清洗、配比怎么定。在 L4 预训练系列第三篇。本系列只给它用到的分类器、聚类、去重三个工具。
- **深度无监督学习**：自编码器、VAE、VQ-VAE。在 L7 多模态系列。
- **统计推断的基础**：标准误、置信区间、p 值的定义。在 L0 第八篇；第六篇直接用。

## 怎么学

### 材料

本系列是最小集的讲解，不替代教材。想补得更扎实：

| 材料 | 读什么 | 说明 |
|---|---|---|
| Andrew Ng, Machine Learning Specialization（Coursera）或 CS229 讲义 | 监督学习、偏差 - 方差、正则化、评估的部分 | 概念最清楚的入门；跳过 SVM 与核方法的推导 |
| Aurélien Géron,《Hands-On Machine Learning with Scikit-Learn, Keras & TensorFlow》 | 第一部分（第 1–7 章）：端到端项目、分类、训练模型、决策树、集成 | 用 scikit-learn 把概念做出来；第二部分是深度学习，不必读 |
| scikit-learn 官方 User Guide | "Model selection and evaluation" 一节 | 交叉验证、指标、校准的权威说明与代码 |
| Broder 1997 / Leskovec 等《Mining of Massive Datasets》第 3 章 | MinHash 与 LSH | 后者免费，一章讲透第五篇的概率 |
| Bishop《Pattern Recognition and Machine Learning》/ Hastie 等《The Elements of Statistical Learning》 | 查阅用 | 想看某个概念的严格版本时翻，不通读 |

### 顺序

两周。第一周读本系列六篇并跑六个脚本；第二周做 Géron 前 7 章的练习、或把脚本改到自己的数据上。做第二篇时回 L0 第六篇对 Bradley-Terry，做第五篇时对 L0 第四篇的概率。

学完的标志不是记住算法，而是**看到 LLM 上的一个问题能叫出它的经典名字**：污染是测试集泄漏、reward hacking 是过拟合、judge 的长度偏好是系统误差、过滤器误杀是精确率召回率的权衡。叫出名字，经典解法就在手边。


## 最终目标

读完这套系列之后，面对 LLM 工作里的一个问题，读者应该能够回答：

```text
benchmark 涨了 5 个点，是真的还是泄漏？                       → 第一篇：测试集只能看一次；第六篇：置信区间与配对
奖励模型准确率 80% 为什么 RL 还钻空子？上限在哪？                → 第一篇：过拟合；第二篇：标注一致性
数据过滤为什么用 fastText 而不是 LLM？阈值怎么定？               → 第三篇：算力账；第六篇：精确率 / 召回率
这批语料里有什么主题？某个主题占太多怎么发现？                    → 第四篇：聚类
Jaccard 0.7 视为重复是怎么来的？                                → 第五篇：S 曲线在 0.685 过 50%
judge 与人一致率 80% 够不够？长度偏好怎么消？                    → 第六篇：一致性、系统误差
"20 个 benchmark 领先 12 个"算不算领先？                        → 第六篇：多重比较，随机期望 10 ± 2.2
```

最终目标是三种能力：

1. **叫出名字**：看到 LLM 上的问题，能说出它是哪个经典概念的重现；
2. **算出数字**：用几十行 scikit-learn 把过拟合、阈值权衡、去重概率、显著性算出来；
3. **用对解法**：知道经典解法（更多数据、正则化、早停、集成、配对检验）在 LLM 上各对应什么。

这一层之后是 L3 深度学习基础：神经网络怎么训、为什么深了就难训——那里的过拟合、正则化、评估，全是本系列的概念换了一个模型。
